## 🔶 Overview
**Cinematic OS** is an elite, intelligent production engine designed to revolutionize the creative pipeline. By orchestrating advanced AI agents and leveraging multi-model generative capabilities, this system acts as an autonomous co-director, handling the heavy lifting of content ideation and production workflow. 

Built with a relentless focus on a sleek, minimalist user experience and high-performance execution, Cinematic OS is engineered for creators who demand nothing but the absolute best.

## ⚡️ Key Features
* **Autonomous Intelligence:** Powered by Google's latest Gemini AI models to generate, refine, and structure elite cinematic concepts.
* **Modern, Fluid UI:** Crafted with React 19 and Framer Motion for a deeply immersive, buttery-smooth interface.
* **Elite Aesthetic:** Minimalist, distraction-free environment optimized for dark-mode workflows.
* **Lightning Fast:** Built on Vite with TailwindCSS for instant feedback and zero-lag creative iteration.

## 🛠️ Tech Stack
* **Core:** React 19, TypeScript, Node.js
* **AI Orchestration:** `@google/genai`
* **Styling & Animation:** Tailwind CSS v4, Framer Motion, Lucide React
* **Build Tooling:** Vite, ESBuild

## 🚀 Quick Start

**Prerequisites:** Node.js installed on your machine.

**1. Clone and Install**
```bash
git clone [https://github.com/your-username/cinematic-os.git](https://github.com/your-username/cinematic-os.git)
cd cinematic-os
npm install
2. Configure Environment
Create a .env.local file in the root directory and add your Gemini API key:

Code snippet
# Required for Gemini AI API calls
GEMINI_API_KEY="your_gemini_api_key_here"

# Used for self-referential links and callbacks
APP_URL="http://localhost:3000"
3. Launch the Engine

Bash
npm run dev
Navigate to http://localhost:3000 to experience the system.

🧠 Architecture
The system utilises a modular, component-driven architecture:

src/main.tsx: Core application entry and provider orchestration.

vite.config.ts: Optimised build pipeline with seamless environment injection.

AI Integration: Direct streaming and parsing through the @google/genai SDK for real-time creative generation.
